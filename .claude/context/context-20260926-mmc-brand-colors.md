# MMC palette update — 2026-09-26

The application brand accents now follow the MMC logo's blue-and-red identity. Primary actions, focus states, selected navigation, and shared brand surfaces use institutional blue (`#1E4F91`, with darker blue variants for hover and dark mode). Red (`#B4233A`) is retained as a restrained secondary brand accent and for meaningful destructive/error/absence states. Neutral surfaces have a subtle cool blue-gray cast to keep the interface calm and readable.

The update intentionally preserves semantic status colors (for example, present/success and late/warning) rather than recoloring every state to match the logo. The calendar's existing layout is unchanged.
