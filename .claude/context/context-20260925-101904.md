# Context — 2026-09-25 10:19 UTC

## Session goal

Move attendance confirmations to top-right toasts with status-matched colors,
use polished toast feedback across the app, keep sound effects restrained,
and improve the data displays on Leaves, Reports, Batches, Interns, and Staff
Accounts.

## Work completed

- Added `src/components/toast-provider.tsx`, mounted in the authenticated
  navigation shell. It provides dismissible, timed, accessible top-right
  notices with distinct absent (red), late (amber), present (green), leave
  (blue), general success, error, and neutral tones. Notifications layer above
  dialogs and respect reduced-motion preferences.
- Attendance status changes now show a top-right toast after the server
  confirms the write. Marking present (clearing an exception) uses the same
  system. A short, subtle two-note Web Audio chime is limited to confirmed
  attendance actions; other routine CRUD and settings actions remain silent.
- Added toast feedback to intern, leave, batch, staff-account, password, and
  session-check actions. Existing inline form errors remain beside the relevant
  form for context.
- Replaced the CSS-transformed mobile tables with purpose-built mobile records
  for intern directory, leave records, attendance breakdown, batches, and staff
  accounts. Kept semantic, horizontally contained desktop tables. The mobile
  records foreground identity and key details, with actions accessible and
  appropriately labeled.
- Added explicit empty states to batches and staff-account views and removed
  unused screen-level imports. Removed the now-obsolete generic mobile table
  transformations from global CSS.
